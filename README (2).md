# Portafolio de Diseño — Fernanda Diaz

Página web para GitHub Pages.

## Archivos

- `index.html` — estructura y contenido.
- `styles.css` — colores, tipografías, formas y diseño responsive.
- `script.js` — animaciones de entrada.
- `img/` — imágenes de proyectos.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `img`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere la página.
